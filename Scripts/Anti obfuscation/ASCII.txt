Это пожалуй самый лёгкий способ расшифровки строк. Чтобы получить исходный код нужно достаточно использовать return или print на данный текст.
Как для примера выглядит такой шифр:

local text = "\108\111\97\100\115\116\114\105\110\103\40\103\97\109\101\58\72\116\116\112\71\101\116\40\34\104\116\116\112\115\58\47\47\114\97\119\46\103\105\116\104\117\98\117\115\101\114\99\111\110\116\101\110\116\46\99\111\109\47\65\68\83\75\101\114\79\102\102\105\99\97\108\47\70\108\111\112\114\83\99\114\105\112\116\115\47\114\101\102\115\47\104\101\97\100\115\47\109\97\105\110\47\83\99\114\105\112\116\115\47\67\114\97\115\104\37\50\48\73\109\97\103\101\34\41"
local function decr(tex)
  return tex
end

Этот метод использует ASCII байты символов. Их можно получить с помощью string.byte(char: string): number, а расшифровать с помощью string.char(byte: number): string
Но если создатель не тупой то он может использовать что-то типо такого рода зашифрования:

function YrNZRytSPCzLaqxDUBwB(code)res=''for i in ipairs(code)do res=res..string.char(code[i]/105)end return res end
